# Personal Notes App 📝

A clean, responsive Notes Application built using **React** for **Project 3** of the **Syntecxhub Web Development Internship**[cite: 32, 35]. This application enables users to create, edit, delete, and view notes with full data persistence using browser local storage[cite: 35].

## 🚀 Features
* **Full CRUD Functionality:** Create new notes, edit existing ones, and delete outdated entries seamlessly[cite: 35].
* **Local Storage Persistence:** Saves notes in `localStorage` so data remains available across page refreshes and browser sessions[cite: 35].
* **Smart Focus Management (`useRef`):** Automatically focuses the title input field when adding or editing notes for a smoother workflow[cite: 35].
* **State Management (`useState`):** Manages local note lists, form inputs, and active edit states dynamically[cite: 35].
* **Clean UI:** Styled with modern CSS for a minimal and user-friendly interface[cite: 35].

## 🛠️ Tech Stack
* **Frontend:** React.js, JavaScript (ES6+), HTML5, CSS3[cite: 35]
* **Hooks Used:** `useState`, `useEffect`, `useRef`[cite: 35]
* **Storage API:** Browser `localStorage`[cite: 35]
